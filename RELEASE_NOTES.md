# New update: Walking, on-device route predictions, saved history

- Added a **Driving / Walking** switch using Mapbox `driving-traffic` and `walking` profiles respectively. Walking alternatives and step descriptions are shown when Mapbox returns them. A driving-only Random Forest is never shown for walking trips.
- Added `model/route_history.js`: local-only history of successful searches (up to 300), per-entry repeat/delete, clear and JSON export. Browser history never stores precise live GPS coordinates.
- Added predicted frequently searched routes and destinations using origin, mode, historical search frequency, and a four-hour Houston time segment (minimum two searches). This **usage-based prediction** is distinct from the historical driving traffic ML model. It does not infer trips physically made.
- Added JS unit tests, expanded mocked browser tests, documentation, and CI checks.
- Preserved the 50-route scheduled driving collector and all existing CSV observations unchanged. Database/sync remains deferred.
